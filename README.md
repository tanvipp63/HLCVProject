# Investigating Sub-Patch Spatial Information

High-Level Computer Vision Project (Summer 2026)

## Project Overview

We investigate whether Vision Transformer patch tokens retain recoverable sub-patch spatial information and study how this information is affected by feature upsampling using AnyUp.
